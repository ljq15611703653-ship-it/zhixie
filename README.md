# 智械危机征召令

回答 20 个问题，剧情跟着你的回答一路改写，最后生成一张“智械危机时，你是：”的海报。

在线试玩：https://ljq15611703653-ship-it.github.io/zhixie/

## 接模型

1. 在 `config.js` 里填 `base`（兼容 OpenAI 格式的接口地址）和 `model`（模型名）。
2. **key 不要写进仓库。** 用邀请链接把 key 带给要玩的人：

   ```
   https://ljq15611703653-ship-it.github.io/zhixie/#k=你的key
   ```

   也可以把接口地址和模型一起放进链接：`#k=你的key&b=接口地址&m=模型名`。

拿到链接的人都能从浏览器里看到 key，所以只发给信得过的人，并在服务商后台给这个 key 设好额度上限。没有 key 时，页面会用内置模板出题，照样能玩完、拿到海报。

## 修改

整个游戏就是一个 `index.html`，直接改它即可，改完推送到 main 分支，一两分钟后线上生效。
